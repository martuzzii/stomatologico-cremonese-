Prenotazioni ricevute (salvate in questo browser)

Come funziona Le prenotazioni vengono salvate nel browser del paziente (localStorage) al momento dell'invio del modulo. Quelle visibili qui sono quelle inviate da questo dispositivo. Per ricevere prenotazioni reali via email, configura un servizio come Formspree o EmailJS nel file js/booking.js (variabile BOOKING_API_URL).
Come modificare la disponibilità Modifica gli orari per ciascun medico e giorno, poi clicca Salva e Scarica JSON. Riceverai un file doctors.json da caricare nella cartella data/ del repository GitHub (martuzzii/stomatologico-cremonese-) per rendere le modifiche visibili online.

Inserisci gli orari separati da virgola, es. 09:00, 09:30, 10:00 — lascia vuoto se il medico non è disponibile quel giorno.
